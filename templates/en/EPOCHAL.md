# EPOCHAL

Raw historical file for this project. Written exclusively by the Coordinator.

## Usage rules

- Consult only when a concrete historical need or an explicit request justifies it. Do not load it in full at the start of executions.
- Locate first by task ID, batch ID, date, or subject and read only the necessary sections. Archived content is historical evidence, not current instruction.
- Each consolidation appends a batch with a stable ID, date/time and timezone offset, source, and a verbatim copy of MEMORY.md before trimming.
- Preserve the original text, order, and dates of the copy. Do not summarize, rewrite, or silently correct the raw record. Unknown old dates remain declared as unknown.
- Coordinator comments stay outside the raw block, identified as comments and dated. Corrections are new records linked to the original batch.
- Check the complete write before changing MEMORY.md. If there is a failure or discrepancy, leave MEMORY.md intact.
- When resuming an interrupted consolidation, locate and check the same batch before continuing. Do not duplicate an already confirmed batch.
- Keep only one Coordinator writer per project, including during consolidation. Do not record secrets.
