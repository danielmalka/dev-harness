# Avisos de terceiros

O conteúdo do kit em `.agents/`, `.skills/`, `.commands/`, `templates/` e `profiles/` é prosa original ou adaptada, escrita para este repositório. Ele é distribuído sob a licença MIT em `LICENSE`.

Este pacote não inclui cópias de marketplaces de agentes de terceiros.

Os documentos HTML carregam o Google Fonts quando há rede (JetBrains Mono, Outfit, Plus Jakarta Sans). Sem rede, continuam legíveis com as fontes de sistema de reserva. Os diagramas Mermaid de alguns docs HTML usam uma CDN e, sem rede, degradam para o texto-fonte. Nem os arquivos de fonte nem o runtime do Mermaid são distribuídos neste repositório.

Os seis sprites de avatar de exemplo embutidos pelo `dh dashboard` (`internal/dashboard/web/sprites/*.png`, nomeados segundo poses do jevmon) são ícones geométricos simples feitos para este kit e distribuídos sob a mesma licença MIT. Eles não contêm arte de terceiros. Os nomes das poses e o formato do `poses.json` seguem o formato documentado pelo projeto jevmon; nenhum código nem ativo do jevmon é copiado.
