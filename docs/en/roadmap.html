Loop planning command

Description: /dh:plan-loop runs a wave-based loop between the implementation-planner (Claude) and a rotation of external CLIs dispatched, for the first time, as planners — not only as reviewers — restricted to binaries with a read-only mode both documented and measured (today only codex; mcode pending measurement; grok, agy and opencode never plan).
