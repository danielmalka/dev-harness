Quick start

From the clone to /dev-harness:doctor and the slice-01 fixture.

01Problem

What hurts today

Sem um caminho curto, o catalogo de 18 papisis not vira trabalho. Este guia liga o clone aos comandos e a uma fatia com resultado conhecido.

02Promise

Load the plugin, run diagnostics, configure the fixture project, and know the slices next command.

Clone doctor setup slice

03Scope

In scope

  • Load command with --plugin-dir.
  • /dev-harness:doctor e /dev-harness:setup.
  • Fixture evals/fixtures/slice-01 (Python 3, unittest, um critisrio vermelho).

Out of scope

  • Publishing, committing, or installing dependencies.
  • Tracks 02 through 07 (resumption, authoring, updates, another AI).
  • Prova de que a sessao Claude descobriu os comandos. Isso ainda is exercicio do user.

04How it works

  1. Clone. Put the repository in a folder of your own. Deactivation details: tutorial 00.
  2. Open Claude in the fixture directory. 
    cd evals/fixtures/slice-01
 claude --plugin-dir "/absolute/path/to/clone/dist/claude-code/dev-harness" --agent coordinator
    Dentro de aspas o ~ not expande: "~/projetos/..." not existe, o Claude ignora o plugin em silencio e --agent coordinator fails com not found. Use $HOME/... ou o caminho completo.
  3. Diagnostics. /dev-harness:doctor. Without Claude, in the clone: bash dist/claude-code/dev-harness/scripts/doctor.sh dist/claude-code/dev-harness.
  4. Setup. /dev-harness:setup com autorizacao para escrever .harness/ so se os arquivos ainda not existirem. Expected profile: none, custom com convencoes de base (a fixture is Python, e Python not is perfil de v1).
  5. Check the red state. python3 -m unittest test_greet.py. AC-02 fails de proposito. Leia BRIEF.md.
  6. Slice. /dev-harness:plan com o brief, depois /dev-harness:build, /dev-harness:verify, /dev-harness:review. Do not copie expected/greet.py no lugar. Compare o unittest com expected/unittest.txt.
  7. Handoff. /dev-harness:handoff. Only the Coordinator writes memory.
