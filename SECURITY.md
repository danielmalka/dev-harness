# Security policy

## Reporting a vulnerability

Report a vulnerability through GitHub private vulnerability reporting: open the repository's Security tab and choose "Report a vulnerability". Do not open a public issue for it.

Include the affected version (the plugin version or the git tag), the steps to reproduce, and the impact you see.

## What to expect

This is a small project with one maintainer. The maintainer reads reports as time allows, replies in the private report, and publishes a fix in a new tagged release. Only the latest release is supported.

## Scope

The kit runs on your machine: the `dh` binary, the Claude Code plugin mod, and a local dashboard bound to `127.0.0.1`. Reports about these are in scope. Flaws in Claude Code itself or in a third-party tool are out of scope; report them to their owners.
