# Política de segurança

## Reportar uma vulnerabilidade

Reporte uma vulnerabilidade pelo relato privado de vulnerabilidades do GitHub: abra a aba Segurança do repositório e escolha "Relatar uma vulnerabilidade". Não abra uma issue pública para isso.

Inclua a versão afetada (a versão do plugin ou a tag do git), os passos para reproduzir e o impacto que você vê.

## O que esperar

Este é um projeto pequeno, com um único mantenedor. O mantenedor lê os relatos conforme o tempo permite, responde no relato privado e publica a correção em uma nova release com tag. Só a release mais recente tem suporte.

## Escopo

O kit roda na sua máquina: o binário `dh`, o mod do plugin do Claude Code e um dashboard local ligado a `127.0.0.1`. Relatos sobre esses itens estão no escopo. Falhas no próprio Claude Code ou em uma ferramenta de terceiros estão fora do escopo; reporte-as aos responsáveis.
