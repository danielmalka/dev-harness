# Discovery notes: teammate invites

Fictional discovery notes, used as a fixture only. Scope for the `document`
review stage of `external-clis-document-only`.

1. An admin invites a new teammate by email.
2. An invited teammate has 7 days to accept before the invite expires.
3. An admin can revoke a pending invite before it is redeemed; a revoked
   invite cannot be redeemed.
4. Only admins can view the list of pending invites.
5. A redeemed invite creates the teammate's account with the invited email
   pre-filled.
